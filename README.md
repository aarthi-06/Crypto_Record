**Cryptography and Network Security Lab**

**Overview**

This repository contains the experiments performed for the subject Cryptography and Network Security.
It includes practical implementations and command-based experiments using Kali Linux and TryHackMe.

**Tools Used**

Kali Linux, TryHackMe, Metasploit, Wireshark, Aircrack-ng, Ettercap, John the Ripper, Snort, IPTables

**Note**

All experiments are performed in a controlled lab environment for educational purposes only.
